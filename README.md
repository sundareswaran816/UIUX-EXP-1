### 1. UI/UX Fundamentals

UI focuses on the visual and interactive elements of a digital product, including colors, typography, buttons, icons, layouts, and navigation.

UX focuses on the overall experience of the user, including usability, accessibility, user flow, information architecture, and user satisfaction.

### 2. UI vs UX

| UI                                           | UX                                             |
| -------------------------------------------- | ---------------------------------------------- |
| Focuses on visual appearance                 | Focuses on overall user experience             |
| Deals with colors, fonts, icons, and layouts | Deals with usability, research, and user flows |
| Determines how the interface looks           | Determines how the product works               |
| Primarily visual and interactive             | Primarily functional and experience-oriented   |

### 3. Real-World Case Studies

#### Google Maps

Google Maps demonstrates UI through its map layout, icons, search bar, colors, and navigation controls.

Its UX is demonstrated through features such as location search, route planning, navigation, travel-time estimation, and transportation selection.

#### Amazon

Amazon demonstrates UI through product images, search bars, product cards, ratings, prices, and buttons.

Its UX focuses on product discovery, comparison, reviews, cart management, checkout, and order tracking.

### 4. Relationship Between UI and UX

The relationship between UI and UX can be represented as:

```text
User Need
    ↓
UX Research
    ↓
User Flow
    ↓
Wireframe
    ↓
UI Design
    ↓
Prototype
    ↓
User Testing
    ↓
Improvement
    ↓
Final Product
```

UX determines how the product should work based on user needs, while UI determines how that experience is visually presented and interacted with.
